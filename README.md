# BOIRO Security

This repository is the central entry point for reporting security vulnerabilities affecting BOIRO products and services.

## Report a vulnerability

Submit vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/Boiro-io/security/security/advisories).

**Do not disclose vulnerabilities through public GitHub issues, discussions, pull requests, or other public channels.**

Read the [BOIRO Vulnerability Disclosure Policy](SECURITY.md) before testing. Active security testing is currently authorized only against `app.boiro.io` and only when performed in accordance with that policy. Other BOIRO-operated assets and customer instances are not authorized targets for active testing.

Vulnerabilities discovered unintentionally on other BOIRO assets may still be reported privately. Stop testing on that asset and submit the information already observed.

Thank you for helping keep BOIRO and its users secure.
